# Hero Card — Оператор Кайл

## 1. Role / Function
Главный playable character, оператор‑исследователь станции.  
Проводник игрока между Обычным и Зеркальным мирами.  
Ключевой носитель механики Phase Shift.

## 2. Narrative Brief
Кайл — инженер, переживший квантовый разлом.  
Его тело частично нестабильно, левая рука распадается в Зеркальной фазе.  
Он пытается стабилизировать Сектор А‑1 и остановить распространение аномалии.

## 3. Visual Constants
1. Янтарный дугообразный визор.  
2. Массивные круглые плечи.  
3. Тяжёлый индустриальный ранец.  
4. Матовый серый композит брони.  
5. Чёткий top‑down силуэт без выступающих деталей.

## 4. Allowed Variations
- Эмоция: нейтральная → сосредоточенная.  
- Ракурс: только top‑down, mid/close.  
- Свет: от мягкого amber до умеренного контраста.  
- Костюм: мелкие технические детали.  
- Состояние: лёгкий glitch, частичный распад руки.

## 5. Forbidden Changes
- изменение формы визора;  
- изменение пропорций torso;  
- яркие цвета вне палитры;  
- органические мутации;  
- разрушение силуэта;  
- изометрия или перспектива.

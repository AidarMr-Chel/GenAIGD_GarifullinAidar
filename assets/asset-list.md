# Key Asset Notes

## 1. Главный терминал
Ключевая gameplay-локация.

Требования:
- строгая геометрия;
- читаемость сверху;
- индустриальные панели;
- локальная янтарная подсветка.

В Зеркальном мире:
- синие разломы;
- glitch overlays;
- neon cracks.

---

## 2. Оператор Кайл
Главный персонаж.

Требования:
- массивный silhouette;
- крупные плечи;
- читаемый visor;
- industrial armor.

Приоритет:
- высокая читаемость сверху;
- узнаваемый outline.

---

## 3. Глитч-форма
Альтернативное состояние персонажа.

Требования:
- частичная деформация;
- digital corruption;
- neon fracture effects.

Не допускается:
- полная потеря силуэта;
- чрезмерный body horror.

---

## 4. UI
UI должен:
- быть минималистичным;
- не перекрывать gameplay;
- использовать phase colors.

Запрещено:
- яркое HUD-перегруженное оформление;
- fantasy-элементы.

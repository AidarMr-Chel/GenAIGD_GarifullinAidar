# План промптов — Занятие 4

**Проект:** Mirrorfall (2D Top-Down Sci-Fi брутализм экшен-рогалик)  
**Камера и ракурс:** Строгий вид сверху (2D top-down view / orthographic projection / flat 2D tile style), фокус на абсолютной читаемости плоской игровой зоны формата 16:9, исключающий изометрические искажения стен.
**Визуальный стиль:** Высокодетализированный 2D-спрайт/тайлсет (High-detail 2D game asset / 16-bit retro-futurism rendering).

## ЧАСТЬ 1: НАПРАВЛЕНИЕ «ЛОКАЦИЯ» (2D Top-Down Арена: Главный терминал Сектора А-1)

### Версия 1.1: 2D-тайлсет Главного терминала — Фаза Безопасности (Обычный мир)
* **Задача генерации:** Создать плоский концепт-план игровой комнаты-арены Главного терминала строго в ракурсе 2D-вида сверху. Геометрия пола должна представлять собой бруталистские серые бетонные плиты с четкой сеточкой швов. По центру локации располагается массивный плоский спрайт главного компьютерного узла, видимый сверху (верхняя панель терминала с тумблерами). Вокруг терминала расположены кабели и трубы, уходящие под стены. Освещение должно быть плоским, с мягким янтарным свечением от горизонтальных мониторов, чтобы игрок четко видел зоны коллизий.

### Версия 1.2: 2D-тайлсет Главного терминала — Фаза Разлома (Зеркальный мир)
* **Задача генерации:** Перегенерировать ту же 2D-арену сверху, применив к плоским текстурам пола и терминала квантовый глитч-эффект Зеркального мира. Серый бетон заменяется на монохромный ультра-черный матовый материал (абсолютный угольный спектр). Плиты пола раскалываются на плоские геометрические воксельные трещины, сквозь которые пробивается высокоинтенсивная неоново-синяя энергия (Electric Blue). Центральный терминал выглядит деформированным, его плоские экраны мерцают и выдают фиолетовые глитч-артефакты (Neon Purple).

## ЧАСТЬ 2: НАПРАВЛЕНИЕ «ПЕРСОНАЖ» (Протагонист: Оператор Кайл)

### Версия 2.1: Спрайт Оператора Кайла — Вид сверху (Обычный мир)
* **Задача генерации:** Разработать концепт-спрайт главного героя, Оператора Кайла, строго сверху (top-down character sprite concept) для создания спрайт-листа ходьбы и бега. Силуэт должен быть массивным, округлым за счет защитного инженерного скафандра. Цветовая палитра: матовый темно-серый композит брони, оранжевые технические полосы, а по центру шлема — дугообразный янтарный светящийся визор, направленный вперед.

Вокруг левой стороны спрайта генерируется ореол из фиолетовых (Neon Purple) цифровых шумов и глитч-полос.
